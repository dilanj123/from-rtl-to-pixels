# From RTL to Pixels

A production-style SystemVerilog image-processing accelerator developed from requirements through RTL, verification, formal analysis, synthesis and measured timing/PPA optimisation.

Status: Phase 0 bootstrap only. No accelerator or reference model is implemented. No functional, formal, synthesis or timing results exist.

Run `make help` and `make doctor`. Only CORE dependencies are mandatory for bootstrap; later workflows must enforce their own dependencies. Unimplemented targets fail explicitly. Nothing installs dependencies automatically.
