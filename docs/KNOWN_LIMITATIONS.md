# Known limitations

Phase 0 only. Tool detection is limited to the current PATH and current Python interpreter; absent from PATH does not prove absent from the machine. No project virtual environment or dependency pins exist. Version probes do not establish functional tool compatibility. No formal solver, simulation, synthesis, ECP5 database, routing, or physical hardware capability is validated. GitHub CLI is unavailable, so account authentication and remote existence are unknown. Documentation placeholders are not Gate-1 specifications; CI is not implemented.
